# KHOTWATI App | تطبيق خطوتي (Frontend PWA)
### *"One Step at a Time." — "خطوة بخطوة"*

Public frontend repository for the **KHOTWATI** habit recovery platform.

## Features
- **Installable PWA**: Offline-ready with Service Worker and Web App Manifest.
- **Multilingual (i18n)**: Full Arabic (RTL, default), French, and English support.
- **Privacy & Anonymity**: No real names, phone numbers, or emails required.
- **Real-Time Community Chat**: Instant WebSockets delivery with rate-limiting and no direct messages.
- **Difficult-Moment Toolkit**: Box breathing exercise, craving countdown timer, 5-4-3-2-1 grounding.
- **Compassionate Restarts**: Restart challenges without shame while preserving historical records.
- **GitHub Pages Ready**: Configured with relative base paths (`base: './'`).

## Development
```bash
npm install
npm run dev
```

## Production Build & Tests
